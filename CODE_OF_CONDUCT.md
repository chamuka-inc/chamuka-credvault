# Code of Conduct

This project adopts the [Contributor Covenant][homepage], version 2.1, as its Code of
Conduct. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we are committed to providing a welcoming, harassment-free experience for
everyone, regardless of background or identity. We expect all participants —
contributors, maintainers, and anyone interacting in project spaces — to act with
respect, empathy, and good faith.

## Scope

This Code of Conduct applies within all project spaces (the repository, issues, pull
requests, and discussions) and in public spaces when an individual is representing the
project.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported
privately to the project maintainers at **conduct@chamuka.io** (or
`swiftugandan@gmail.com` if that bounces). All complaints will be reviewed and
investigated promptly and fairly. Maintainers are obligated to respect the privacy and
security of the reporter of any incident.

Maintainers will follow the Contributor Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
in determining the consequences for any action they deem in violation.

[homepage]: https://www.contributor-covenant.org
